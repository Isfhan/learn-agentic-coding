# 💬 Prompt Engineer — Entry Track

> **⏱️ Time:** ~10 hours of this roadmap (light touch) · **Track:** Tier 2 (entry) · **Start:** Step 02

An honest heads-up: in 2026, **standalone prompt engineer titles are declining** and merging into AI Engineer. But the *skill* is still the front door to the field — prompt engineering is the easiest entry point, and most applied roles pay a real premium for it. Use this track as a launchpad, not a destination.

---

## 💼 What this role actually does

- Designs prompts and system prompts that get reliable output from models.
- Builds eval suites so prompt changes are measured, not vibes ([Step 14](../steps/14-evals-testing.md)).
- Works closest to the model of anyone on the team — a great observation post for growing.

**Exit paths after 6–12 months:** AI Engineer (code + prompts), Automation Engineer (prompts that drive workflows), AI PM (prompts + product judgment).

## ➕ Role-only additions (what the steps don't cover)

- **System prompt design:** write, version, and A/B-test system prompts like code (git them).
- **Prompt injection defense:** learn to spot and neutralize injection vectors early ([Step 15](../steps/15-security-safety.md) is your friend).
- **Measured iteration:** every prompt change ships with a before/after eval ([Step 14](../steps/14-evals-testing.md)) — this is what separates professionals from hobbyists.

---

## 🚀 Track capstone

1. Pick a task (e.g., "summarize roadmap steps for beginners").
2. Write a system prompt, then **iterate 5 times** with an eval suite tracking pass rates.
3. Publish the before/after table — this portfolio piece proves you understand *measured* prompt engineering, which is exactly what hiring managers want to see.
4. Then start [Step 16](../steps/16-build-your-own-agent.md) and graduate to the [AI Engineer track](./ai-engineer.md).
